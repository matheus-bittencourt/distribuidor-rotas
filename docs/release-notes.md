Executável Windows para uso isolado (pen drive).

1. Baixe `DistribuidorRotas-windows.zip` e extraia a pasta no pen drive.
2. Abra `DistribuidorRotas.exe`. Leia `LEIA-ME.txt` dentro da pasta.

- Roda só no computador onde é aberto: nenhuma conexão sai dele (bloqueio no nível do sistema).
- Endereços, rotas por ruas e fundo do mapa vêm do pacote de mapa offline incluído na pasta.
- Ao abrir, sem nenhuma lista carregada, o app procura uma versão nova do mapa (manifesto assinado). Dá para desligar na tela.
- O executável não é assinado digitalmente: o Windows pode pedir confirmação na primeira vez.
